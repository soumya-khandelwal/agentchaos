  1. 01. Core Concepts: Why Agents Break

    • The 3 stages of a tool call

  2. 02. Architecture & Technical Design

  3. 03. Guided Code Walkthrough

    • 4-file reading order to understand the repo in 5 minutes

  4. 04. Testing Guide & Test Catalog

    • CLI and pytest command cheat sheet
